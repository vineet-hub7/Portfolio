NEC IR Transmitter & Receiver on FPGA

Full-duplex NEC infrared transceiver system built on the Vicharak Shrike development board — combining a Renesas FPGA for real-time protocol encoding/decoding with an RP2040 microcontroller for host communication over a custom 2-wire synchronous serial interface.

Overview

Consumer IR remotes use the NEC protocol — a pulse-distance encoding scheme operating at a 38 kHz carrier frequency. This project implements a complete NEC transceiver in synthesisable Verilog: the FPGA receives transmit commands from an RP2040 MCU over a 2-wire link (DATA + CLOCK), modulates them onto a 38 kHz IR carrier via an LED, and simultaneously listens for incoming IR signals through a TSOP1738 sensor. Decoded frames (address + command) are reported back to the MCU in real-time, completing a full loopback verification chain.

The entire system was designed, simulated, and deployed on the Vicharak Shrike board — a compact FPGA+MCU development platform — as part of an internship project at Vicharak.

Verilog Module Hierarchy

  • ir_top.v — Top-level module integrating all sub-modules and managing inter-module routing
  • nec_encoder.v — NEC protocol encoder generating AGC leader, address/command bits with pulse-distance timing, and repeat code support
  • nec_decoder.v — NEC protocol decoder with edge-detection, bit-width measurement, and frame validation (address + inverted address check)
  • carrier_generator.v — Precision 38 kHz square-wave generator derived from 50 MHz system clock (counter-based frequency division)

NEC Protocol Implementation

Transmission Frame Structure

Phase Duration Description
AGC Leader (Mark) 9 ms 38 kHz burst — alerts the receiver that a frame is starting
AGC Leader (Space) 4.5 ms Silent gap separating leader from data
Logic '0' 562.5 µs mark + 562.5 µs space Short space indicates a zero bit
Logic '1' 562.5 µs mark + 1687.5 µs space Long space indicates a one bit
Repeat Code 9 ms mark + 2.25 ms space + 562.5 µs burst Sent when a remote button is held down

Testbench Verification

A comprehensive self-checking testbench (tb_ir_top.v) validates the entire loopback chain: Serial RX → NEC Encode → IR Modulation → TSOP Decode → NEC Decode → Serial TX. The testbench verifies:

  • Correct 9 ms AGC leader pulse generation with 38 kHz modulation
  • Accurate pulse-distance encoding of all 32 data bits (address + inverted address + command + inverted command)
  • NEC Repeat Code generation (9 ms + 2.25 ms + burst) for held buttons
  • Full loopback: transmitted address and command match decoded values byte-for-byte
  • Serial frame integrity over the 2-wire synchronous interface

Physical Components

  • Board: Vicharak Shrike — Renesas FPGA (1120 LUTs) + RP2040 MCU
  • IR Transmitter: 940 nm IR LED with 220Ω current-limiting resistor
  • IR Receiver: TSOP1738 (38 kHz tuned) infrared sensor
  • MCU Software: MicroPython running on RP2040
  • FPGA Toolchain: Renesas Go Configure for synthesis and bitstream generation
